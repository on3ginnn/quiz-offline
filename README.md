# Quiz Offline

Два Windows-приложения (PyQt6):

- **Quiz Offline** — плеер: офлайн-прохождение тестов по пакетам (schema v3).
- **Quiz Admin** — конструктор для администраторов: тесты, мультитесты, сценарии прохождения, выгрузка пакета для плеера.

Тест хранит только вопросы; **сценарий прохождения** задаёт, как их воспроизводить (время, попытки, пороги оценок, квоты тем). Пакет = тест + сценарий — его загружают в плеер.

## Установка и запуск в dev

Отдельный проект (не часть репозитория сайта). Нужен Python 3.12+ и Windows.

```bash
python -m venv venv
venv/Scripts/activate
pip install -e ".[dev]"
python -m quiz_offline.main   # плеер
python -m quiz_admin.main     # конструктор
```

Если при импорте `PyQt6` ошибка `source code string cannot contain null bytes` — пакет повреждён; переустановите:

```bash
pip install --force-reinstall --no-cache-dir PyQt6 PyQt6-Qt6 PyQt6-sip
```

## Тесты

```bash
pytest
```

## Сборка exe (Windows)

```bash
pip install -e ".[build]"
pyinstaller quiz_offline.spec   # плеер
pyinstaller quiz_admin.spec     # конструктор
```

Артефакты: `dist/QuizOffline/QuizOffline.exe` и `dist/QuizAdmin/QuizAdmin.exe` (+ папка `_internal`, ~70–130 MB каждый).

## Структура на флешке

```
QuizOffline/
  QuizOffline.exe
  _internal/          # зависимости PyInstaller
  rooms/              # копии JSON при «Добавить комнату»
  data/
    journal.sqlite    # журнал участников (создаётся автоматически)
```

**Важно:** запускайте программу **с флешки**, чтобы `data/journal.sqlite` оставался на носителе и журнал не разъезжался по компьютерам.

## Конструктор (Quiz Admin)

Данные: `data/admin.sqlite` рядом с exe; выгрузки по умолчанию — в `exports/`.

1. **«+ Новый тест»** (обычный или мультитест) либо **«Импорт JSON…»** (тест, мультитест или готовый пакет).
2. Вкладка **«Вопросы»**: добавьте вопросы, типы «один / несколько правильных», **«Сохранить вопросы»**. У мультитеста вкладка **«Темы и вопросы»**: новая тема, тема из существующего теста, порядок.
3. **«Объединить в мультитест…»** на главном экране — выбранные тесты становятся темами.
4. Вкладка **«Сценарии прохождения»**: **«+ Сценарий»** → время, попытки, перемешивание, режим выборки, показ результатов, пороги оценок, квоты по темам.
5. **«Выгрузить пакет для плеера…»** — файл JSON; проверка выполняется до записи.

## Сценарий работы плеера

1. Получите JSON-пакет из конструктора.
2. Скопируйте JSON на флешку.
3. В программе: **«+ Добавить комнату»** (справа от заголовка списка) или кнопка в пустом состоянии → выберите JSON.
4. На карточке комнаты нажмите **«Войти →»** → в зале **«Начать попытку»** → укажите фамилию, имя и при необходимости отчество.
5. На экране вопроса: **«Завершить попытку»** в шапке или **«Далее →»** / **«Завершить тест»** внизу (кнопка CTA). Навигация слева направо: **← Назад** → **Далее** → **Очистить выбор** (если есть ответ). Варианты ответа — крупные карточки целиком; сверху полоса прогресса, таймер краснеет за минуту до конца. Клавиши **↑↓** перемещают фокус по вариантам, затем по кнопкам; **Enter** / **Пробел** — выбор варианта или действие кнопки.
6. После результата: кольцо — прогресс по **%**, в центре — **оценка**, подпись **«N из 5»** (без дублирования процента). **«Пройти ещё раз»** — акцентная кнопка (primary); **«Покинуть тест»** — возврат в зал.

**Главный экран:** карточки комнат (заголовок `{тест} · {комната}`), мета-бейджи (лимит попыток, «Прошли: N» — прошедшие ≥1 попытку, время и число вопросов), меню ⋮ (**«Заменить файл комнаты…»**), поиск при двух и более комнатах, empty state при отсутствии комнат.

**Зал:** тот же заголовок `{тест} · {комната}`; под ним бейджи политики (попытки, лимит времени, вопросы, для мультитеста — число тем); кнопка **«Начать попытку»** справа в шапке. Счётчик 👥 на карточке Home совпадает с числом строк в журнале зала (только участники с завершённой попыткой).

**Прохождение:** крупный шрифт, карточки вариантов, футер **← Назад | Далее → | Очистить выбор**; клавиатура **↑↓/Enter**.

**Размер текста (для слабовидящих):** в правом верхнем углу обеих программ — **А− / А+** (100 / 125 / 150 / 200 %), горячие клавиши **Ctrl+=**, **Ctrl+−**, **Ctrl+0**. Выбор запоминается между запусками (QSettings).

**Результат:** заголовок «Оценка N», кольцо — дуга по `weighted_percent`, в центре цифра оценки; подпись **«N из 5»**; **«Пройти ещё раз»** — `primary` CTA.

Все параметры прохождения (время, попытки, пороги, shuffle, квоты) берутся из пакета комнаты.
